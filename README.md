# Tela de Login - Projeto PIM

Este repositório contém a implementação de uma interface de login desenvolvida para o projeto acadêmico (PIM/Projeto de Extensão). O objetivo é demonstrar conceitos fundamentais de desenvolvimento front-end, focando em estrutura, estilização e interatividade.

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando as tecnologias web fundamentais:

*   **HTML5:** Estruturação semântica da página.
*   **CSS3:** Estilização moderna, utilizando Flexbox para centralização e design responsivo.
*   **JavaScript:** Lógica de manipulação de DOM e validação de campos.

## 📁 Estrutura do Projeto

A organização dos arquivos segue o padrão:

*   `login.html`: Estrutura principal da página de login.
*   `styles.css`: Definições visuais, cores e tipografia.
*   `script.js`: Comportamentos e interações do formulário.

## 💻 Como executar o projeto

1.  Clone este repositório para sua máquina local:
    ```bash
    git clone [https://github.com/USCS-ADS/TelaDeLoginPim.git](https://github.com/USCS-ADS/TelaDeLoginPim.git)

2.  Abra o arquivo `login.html` em qualquer navegador moderno.

## 🛠️ Funcionalidades

- [x] Layout responsivo para dispositivos móveis e desktop.
- [x] Campos de entrada para E-mail e Senha.
- [x] Validação de preenchimento via JavaScript.
- [x] Estilização customizada com foco em UX (Experiência do Usuário).
